## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### 1. Clone or Open Project
```bash
git clone https://github.com/Kube030106/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Create Production Build
```bash
npm run build
```
Production assets are generated in the `dist/` directory.

## 🌐 1-Click Deployment Instructions

### Deploy to Vercel
1. Push your repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. The included `vercel.json` automatically handles single-page application routing.
5. Click **"Deploy"**!

### Deploy to Netlify
1. Go to [netlify.com](https://netlify.com) and import your repository.
2. The included `netlify.toml` preconfigures `npm run build` and `dist` directory with SPA 200 redirects.
3. Click **"Deploy site"**!

### Deploy to GitHub Pages
The repository includes `.github/workflows/deploy.yml`:
1. Push this project to GitHub on the `main` branch.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The GitHub Action will automatically build and publish the site!
